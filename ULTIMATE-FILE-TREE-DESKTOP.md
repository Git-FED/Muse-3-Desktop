# Desktop Buddy desktop tree

Desktop addition to Muse Number 3. The Android tree remains unchanged.

- `package.json` — Electron and electron-builder configuration
- `package-lock.json` — generated by npm install
- `main.js` / `preload.js` — isolated BrowserViews and safe IPC
- `renderer/` — toolbar and 40px black switcher bar
- `assets/` — master icon and platform conversions
- `.github/workflows/build-desktop.yml` — Windows/macOS/Linux builds
